问题反馈

      
遇到回收异常、守护掉线、WebUI 问题，把诊断信息一起发过来最快。

      

        
        
      

      
    
        
  • 手机型号、Android 版本、内核版本
    • 
        
  • 用的是 Magisk / KernelSU / APatch，以及版本号
    • 
        
  • 出现问题的场景（游戏、切后台、息屏、开机多久）
    • 
        
  • 日志：概览页最下面的「运行日志」
    • 
        
  • 诊断信息：点上面的「复制诊断信息」，粘贴到 Issue 里
    • 
        
  • 机型、Android / 内核版本、root 方案
    • 
        
  • 复现步骤：游戏 / 切后台 / 息屏 / 开机多久
    • 
        
  • 概览页的「运行日志」或「自检」输出
